# Kuzushiji Character Recognition

This project explores classical Japanese character recognition using the Kuzushiji dataset.

A CNN-based deep learning model was implemented using TensorFlow/Keras.  
To address data imbalance and limited samples, data augmentation strategies were explored, including GAN-assisted augmentation as part of the training pipeline.

The project focuses on:
- Model implementation
- Training experimentation
- Data imbalance handling
- Evaluation and behavior analysis

## Tech Stack
Python, TensorFlow, Keras, CNN, GAN, NumPy
